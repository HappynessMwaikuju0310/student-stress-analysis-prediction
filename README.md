# Student Stress Analysis and Prediction

## What This Project Does
I used survey data from students to study what causes stress. I cleaned the data, made charts to see the biggest stress factors (like sleep and workload), then built a Python model that could predict a person's stress type. It got the right answer about 94% of the time, and I saved the model so it could be reused.

## Why It Matters
Schools and universities could use a tool like this to spot students who need support early.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn (for charts)

## Dataset
Sourced from Kaggle.
